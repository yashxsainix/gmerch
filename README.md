# GMerch ✨ - Cute Pet Merch E-Commerce

Welcome to the **GMerch** codebase! This is a fully functional, static, mobile-first e-commerce frontend tailored for an ultra-cute, pastel pet brand. 

## 🛠 Tech Stack
- **HTML5** (Semantic & Accessible)
- **Tailwind CSS** (via CDN with custom config)
- **Vanilla JavaScript** (No build step, clean code)
- **Three.js** (via CDN for the hero section 3D rotating collar)
- **GSAP & Vanilla-tilt.js** (via CDN for bouncy, smooth animations)
- **Canvas-Confetti** (via CDN for that extra dopamine hit on adding to cart)
